WHY THIS STRUCTURE IS KEPT SMALL
- One backend folder, one frontend application and one database.
- One React application serves both /admin and /patient routes.
- Only the five business services are separated because they contain different logic.
- Exactly two source CSV files remain in data/.
- Forecast outputs, resource plans, rosters and alerts are stored in PostgreSQL, not as additional manually maintained CSV files.

SUGGESTED CREATION ORDER IN VS CODE
1. Create rural-healthcare-ai and open it in VS Code.
2. Create the root files: README.md, .gitignore, .env.example and requirements.txt.
3. Create data, backend, frontend, scripts and tests.
4. Inside backend, create services and artifacts.
5. Create the listed backend Python files.
6. Create the React/Vite application inside frontend, then replace its src structure with the folders above.
7. Place only demand_resource_daily.csv and staff_master.csv inside data.
8. Initialize Git from the root folder.

GIT COMMANDS (RUN FROM THE ROOT FOLDER)
git init
git add .
git commit -m "Initialize rural healthcare AI project"
git branch -M main
git remote add origin <YOUR_GITHUB_REPOSITORY_URL>
git push -u origin main
git checkout -b develop
git push -u origin develop

IMPORTANT
- Do not commit .env, node_modules, Python virtual environments, __pycache__, local database dumps or logs.
- Use .env.example to show variable names such as DATABASE_URL and SECRET_KEY without exposing real values.
- Keep generated model files in backend/artifacts only when they are small enough for normal repository use; otherwise document how to recreate them.
